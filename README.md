# Algoritmos e Estrutura de Dados 2 (AED2)

Algoritmos e trabalhos em C da disciplina de AED2.

## Estrutura
- `AlgortimosdeOrdenação/`: ordenação e sistema de cadastro.
- `DadosAbstratos/` e `EstruturaDeDados/`: TADs e estruturas (estacionamento, estoque, álbum de fotos, clínica, garagem, playlist, rede social).
- `ManipulaçãoArquivo/`: manipulação de arquivos (concessionária, lâmpada).
- `TrabalhoFinal/`: `escola.c`.
- `TrabalhoAED2/`: trabalho (`main.c`, diagrama).

Compilar com `gcc arquivo.c -o programa`.
